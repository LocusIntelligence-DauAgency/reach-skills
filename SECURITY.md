# Security

Please report security issues privately to [hello@locus-intelligence.com](mailto:hello@locus-intelligence.com) with "Security" in the subject line. Do not open a public issue for a vulnerability.

Include what you found, the steps to reproduce it and the impact you expect. Test only against your own Reach account and your own Google Business Profile; never access or change data that is not yours.

We will confirm receipt and keep you updated while we fix it.

The hosted server is at `https://reach.locus-intelligence.com/api/mcp`. This repository contains documentation and metadata only; there is no server code here.
